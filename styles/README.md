# CSS Architecture Documentation

Этот документ описывает архитектуру CSS файла `globals.css` и переиспользуемые классы.

## 📁 Структура файла

Файл организован по секциям для лучшей читаемости и поддержки:

### 1. BASE STYLES
Базовые стили для темной темы и отключения выделения текста.

### 2. LAYOUT UTILITIES
Утилиты для компоновки и позиционирования элементов.

#### Flex утилиты:
- `.flex-center` - центрирование по обеим осям
- `.flex-start` - выравнивание по началу
- `.flex-end` - выравнивание по концу
- `.flex-between` - распределение между элементами

### 3. SCROLLBAR STYLES
Переиспользуемые стили для скроллбаров.

#### Базовые классы:
- `.scrollbar-base` - базовый тонкий скроллбар
- `.scrollbar-hidden` - скрытый скроллбар

#### Тематические скроллбары:
- `.scrollbar-teal` - бирюзовый скроллбар для комментариев
- `.scrollbar-gray` - серый скроллбар для чатов
- `.scrollbar-minimal` - минимальный скроллбар

### 4. GLASSMORPHISM & BACKDROP EFFECTS
Эффекты стекла и размытия фона.

#### Базовые классы:
- `.glass-base` - базовый эффект стекла
- `.glass-light` - светлое стекло
- `.glass-dark` - темное стекло
- `.glass-card` - стекло для карточек

### 5. BUTTON STYLES
Переиспользуемые стили кнопок.

#### Базовые классы:
- `.btn-base` - базовый стиль кнопки
- `.btn-primary` - основной стиль кнопки

#### Специализированные кнопки:
- `.black_btn` - черная кнопка с cyan hover
- `.chat_btn` - кнопка чата с lime hover
- `.outline_btn` - кнопка с красным hover
- `.copy_btn` - кнопка копирования

### 6. INPUT STYLES
Стили для полей ввода.

#### Базовые классы:
- `.input-base` - базовый стиль поля ввода
- `.form_input` - стиль для обычных полей
- `.form_textarea` - стиль для текстовых областей
- `.search_input` - стиль для поиска

### 7. TYPOGRAPHY & GRADIENTS
Типографика и градиентные тексты.

#### Градиентные тексты:
- `.gradient-text-base` - базовый градиентный текст
- `.blue_gradient` - синий градиент
- `.green_gradient` - зеленый градиент
- `.orange_gradient` - оранжевый градиент
- `.red_gradient` - красный градиент

### 8. LIST COMPONENTS
Компоненты списков.

#### Базовые классы:
- `.list-base` - базовый стиль списка
- `.message-list` - список сообщений
- `.chat-list` - список чатов
- `.comment-list` - список комментариев

### 9. DROPDOWN COMPONENTS
Компоненты выпадающих меню.

#### Классы:
- `.dropdown` - базовый выпадающий список
- `.dropdown-link-base` - базовая ссылка в dropdown
- `.dropdown_link_profile` - ссылка профиля
- `.dropdown_link_post` - ссылка поста
- `.dropdown_link_chat` - ссылка чата

## 🎯 Примеры использования

### Создание кнопки с эффектом стекла:
```html
<button class="btn-primary glass-light">
  Кнопка
</button>
```

### Список с кастомным скроллбаром:
```html
<div class="list-base scrollbar-teal">
  <!-- содержимое списка -->
</div>
```

### Градиентный заголовок:
```html
<h1 class="head_text blue_gradient">
  Заголовок
</h1>
```

### Поле ввода с эффектом стекла:
```html
<input class="input-base glass-dark" />
```

## 🔧 Преимущества новой архитектуры

1. **Модульность** - каждый класс отвечает за одну функцию
2. **Переиспользуемость** - классы можно комбинировать
3. **Читаемость** - четкая структура и комментарии
4. **Поддерживаемость** - легко найти и изменить стили
5. **Консистентность** - единообразие в дизайне

## 📝 Рекомендации

1. Используйте базовые классы как основу
2. Комбинируйте классы для создания сложных эффектов
3. Добавляйте новые классы в соответствующие секции
4. Следуйте принципу DRY (Don't Repeat Yourself)
5. Документируйте новые классы в этом файле
